# Лабораторная работа № 3. Одномерные массивы

Вариант 6. Программа читает из файла целое `M`, число `GRN` и восемь элементов массива `VEC`. Числа разделяются пробелами или переносами строк. В дробных числах используется точка.

## Алгоритм

Программа проходит по `VEC` справа налево и записывает накопленные суммы в `NEWVEC`. Затем она добавляет `GRN` и сумму модулей первых `M` элементов `VEC`. За один проход по `NEWVEC` вычисляется общая сумма и ищется наименьший положительный элемент. Если он встречается несколько раз, выводится первый индекс. Индексация начинается с нуля.

Размер `VEC` задаётся константой. Допустимые значения `M` — от нуля до размера массива включительно. При `M = 0` сумма модулей равна нулю. Программа проверяет, что файл открылся и содержит ровно нужное количество корректных чисел.

## Сборка и запуск

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o laba-3
./laba-3 input.txt
```

Для входных данных из `input.txt` результат такой.

```text
NEWVEC: 3 -1 1 0 0 4 1 3 -2 5
Сумма: 14
Наименьший положительный элемент: NEWVEC[2] = 1
```

## Проверка

Программа собрана и проверена на Raspberry Pi (AArch64, GCC 15.2.0). Прошли 15 проверок, включая пример выше, `M = 0` и `M = 8`, дробные значения, файл без переноса строки в конце, отсутствие положительных элементов и ошибки входных данных.
